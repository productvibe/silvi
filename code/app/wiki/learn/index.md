This course takes you from opening the app to a report on your own data. It
takes about an hour.

You learn by doing. Each lesson gives you things to say to Claude in the Code
tab of the Claude desktop app. Claude does the work, says what it changed,
and you check the result in your browser. You never type a command.

## The lessons

| Lesson | Page | You end with |
|---|---|---|
| 1 | [Setup](/wiki/learn/setup) | The app running, the example reports open, your database connected |
| 2 | [Your first report](/wiki/learn/start) | A report on one of your tables |
| 3 | [Make it yours](/wiki/learn/next) | Charts, a table, the "(i)" dialog, the date filter and an input |

After the course, look things up in [Components](/wiki/components) and get
single jobs done with the [Guides](/wiki/guides).
