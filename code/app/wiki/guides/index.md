Each guide gets one job done. You read it, then say the prompts to Claude in
the Code tab.

| Guide | Use it to |
|---|---|
| [Connect your database](/wiki/guides/connect-database) | Fill in your connector's keys and check the reports reach the database |
| [Build a report](/wiki/guides/build-a-report) | Ask for a new report and get it right first time |
| [Ask Claude](/wiki/guides/ask-claude) | Phrase requests that work well for reports |
| [Fix problems](/wiki/guides/fix-problems) | Deal with "Not connected", a failing check or a wrong figure |
| [Write wiki pages](/wiki/guides/wiki-pages) | Add your own pages to this wiki |
